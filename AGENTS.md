## Project Overview

English synonym finding game to improve recall and paraphrasing skills.

## Coding

- Write minimal code focused on the request.
- Use clear noun names for variables and classes.
- Use clear verb names for functions.
- Use short functions with maximum six lines.
- Add types in function declarations except None return.
- Add variable type if the initialized value doesn't make it obvious.

## Commits
- Start with add/ref/fix/opt, then a colon.
- Then one lowercase sentence in present simple tense.
